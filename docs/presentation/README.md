# Презентация и ролик StepPay

- `StepPay_Project_Complete.pptx` - презентация, 15 слайдов, верхнее меню на всех слайдах, переходы morph.
- `StepPay_video.mp4` - ролик 1920x1080, 61 секунда, в стиле презентации.
- `build_deck.py` - сборка слайдов поверх исходного файла автора (python-pptx).
- `video-src/` - исходники ролика на Remotion. Сборка: `npm i`, затем `npx remotion render StepPay out.mp4`.
