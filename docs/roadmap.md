# StepPay — план разработки по этапам

Стек: монорепо (pnpm), TypeScript. Фронтенд — Next.js на **Vercel**, бэкенд (API + Postgres) — на **Railway**.
Деньги в копейках (целые числа), ядро сделок — чистые функции без зависимостей, чтобы легко переехать на платформу ЦБ.

| # | Этап | Результат | Статус |
|---|------|-----------|--------|
| 1 | Ядро сделок (`packages/engine`) | Состояния этапов, резерв/выплата/возврат, 3 режима, споры, автоприёмка, комиссия; тесты на инвариант «деньги не теряются» | ✅ |
| 2 | API (`apps/api`, Railway) | Fastify + Postgres, пользователи (демо-вход), кошелёк-эмулятор, CRUD сделок, шаблоны (ванная, кухня, электрика, сайт, свадьба), журнал операций, cron-тик автоприёмки | ✅ |
| 3 | Веб-приложение (`apps/web`, Vercel) | Mobile-first PWA по макетам: Сделки, Проекты (краудфандинг/гранты), «+» мастер создания, Кошелёк, Профиль; роли заказчик/исполнитель | ✅ |
| 4 | Приёмка и споры в UI | Фото при сдаче этапа (сжатие на устройстве, хранение в API), переписка по спору с фото, решение приёмщика с комментарием, видно «кто и как принял этап» | ✅ |
| 5 | «Прогрессивный» слой | Живые обновления (SSE) и уведомления (в браузере, когда вкладка скрыта), анимация пересчёта денег с «монетами», тёмная тема, рейтинг исполнителя и публичная карточка, демо-чеки самозанятого, AI-помощник на Claude (разбивка работ на этапы и критерии приёмки; без ключа — подбор шаблона) | ✅ |
| 6 | Демо-режим | Страница `/demo`: 8 шагов сценария из презентации (ремонт 300 тыс. ₽ → краудфандинг с возвратом остатка), сервер сам действует за участников, просмотр «глазами» любого из них, сброс данных, наполненный каталог проектов | ✅ |
| 7 | Деплой и релиз | Dockerfile и `railway.json` для API, `vercel.json` для веба, CI (typecheck + тесты + сборка), README с пошаговым деплоем и переменными. **Сам деплой выполняется владельцем аккаунтов Railway/Vercel** | ✅ конфигурация готова |

Решения, которые принимаем по ходу: логин (демо-вход по роли vs. e-mail), хостинг файлов фото (S3-совместимое хранилище Railway), AI-провайдер для этапа 5.
| 8 | Регистрация | Вход и регистрация по телефону и коду (доставка подключаемая, сейчас демо), один профиль на все роли, поиск исполнителя по телефону или имени, `DEMO_MODE=off` убирает демо-аккаунты и демо-данные | ✅ |
| 9 | Новый дизайн | Строгий банковский стиль в синих тонах ВТБ: карточка кошелька, быстрые действия, плитки показателей, цветные статусы сделок, версия для компьютера с боковым меню и входом в два столбца | ✅ |
