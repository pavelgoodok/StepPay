# StepPay — оплата по шагам

Деньги резервируются в цифровых рублях и уходят исполнителю частями, только когда этап принят. Один движок, три режима: **свой проект** (ремонт, сайт, свадьба), **краудфандинг** (поддержка и предзаказ, не инвестиции) и **грант**.

Прототип без реальных денег: кошелёк цифрового рубля эмулируется. Описание для заявки — `docs/application.md`, план по этапам — `docs/roadmap.md`.

## Устройство

| Часть | Что внутри | Где живёт |
|---|---|---|
| `packages/engine` | Ядро сделок: чистые функции, суммы в копейках, этапы, резерв/выплата/возврат, споры, автоприёмка, комиссия. Не зависит от БД и сети, поэтому его можно перенести на платформу ЦБ | — |
| `apps/api` | Fastify + Postgres: демо-вход, кошелёк, сделки, шаблоны, фото, SSE-события, AI-помощник (Claude), репутация, чеки, демо для жюри | Railway |
| `apps/web` | Next.js, mobile-first: сделки, проекты, кошелёк, профиль, мастер создания, тёмная тема | Vercel |

Состояние движка хранится целиком в Postgres (одна строка `jsonb` + таблица фото), все изменения идут через одну очередь внутри процесса. Поэтому **API работает в одном экземпляре** — для прототипа этого достаточно.

## Запуск локально

Нужны Node 22 и pnpm 10.

```bash
pnpm install
pnpm test            # тесты ядра и API
pnpm typecheck

# API на :4000 (без DATABASE_URL данные хранятся в памяти)
cd apps/api && pnpm start
# веб на :3000
cd apps/web && NEXT_PUBLIC_API_URL=http://localhost:4000 pnpm dev
```

Откройте http://localhost:3000 и нажмите «Демо-сценарий для жюри».

## Деплой

### 1. API на Railway
1. New Project → Deploy from GitHub repo → выберите репозиторий. Корневой `railway.json` включит сборку из `apps/api/Dockerfile`.
2. Add → Database → PostgreSQL. Railway сам добавит `DATABASE_URL` в сервис (при необходимости — через ссылку на переменную Postgres-сервиса).
3. Variables сервиса API:

| Переменная | Значение |
|---|---|
| `AUTH_SECRET` | длинная случайная строка (**обязательна** в production), например `openssl rand -hex 32` |
| `CORS_ORIGIN` | адрес фронтенда, можно несколько через запятую: `https://steppay.vercel.app,https://steppay-git-main.vercel.app` |
| `ANTHROPIC_API_KEY` | ключ для AI-помощника. Без него работает запасной подбор шаблона |
| `ANTHROPIC_MODEL` | необязательно, по умолчанию `claude-opus-5-5` |
| `DEMO_MODE` | `off` отключит публичные демо-эндпоинты (сброс данных и сценарий). Для жюри оставьте включённым |

4. Settings → Networking → Generate Domain. Проверка: `https://<домен>/health` отвечает `{"ok":true}`.

### 2. Веб на Vercel
1. Add New → Project → тот же репозиторий, **Root Directory: `apps/web`**.
2. Environment Variables: `NEXT_PUBLIC_API_URL` = адрес API из Railway (без слэша на конце).
3. Deploy. Затем вернитесь в Railway и впишите адрес Vercel в `CORS_ORIGIN`.

Фронтенд и API на разных доменах — это нормально: токен хранится в `localStorage`, события приходят по SSE с токеном в запросе.

### 3. Проверка после деплоя
Откройте сайт → «Демо-сценарий для жюри» → пройдите 8 шагов. В Railway должна появиться таблица `app_state`, после перезапуска сервиса данные остаются.

## Демо для жюри (3 минуты)

Страница `/demo` сама совершает действия за нужных участников, а вы показываете результат «глазами» каждого:

1. Анна создаёт ремонт ванной за 300 000 ₽ в 4 этапа.
2. Анна резервирует деньги — у Ивана «300 000 ₽ зарезервировано».
3. Иван сдаёт этап «Плитка» с фото.
4. Анна жмёт «Принял» — у Ивана +120 000 ₽.
5. Тот же движок: краудфандинг настольной игры на 300 000 ₽.
6. Ольга и Максим вносят по 150 000 ₽.
7. Автор сдаёт «Макет», спонсоры принимают — автору 100 000 ₽.
8. Автор срывает «Тираж»: остаток 200 000 ₽ возвращается спонсорам.

«Сбросить данные и начать заново» возвращает чистое состояние с наполненным каталогом проектов.

## Ограничения прототипа

- Кошелёк цифрового рубля и смарт-контракты ЦБ эмулируются; платформа ЦБ для коммерческих смарт-контрактов пока существует только как концепция.
- Вход — демо-пользователи без паролей. В публичном продакшене нужна настоящая аутентификация, а публичные демо-эндпоинты стоит отключить (`DEMO_MODE=off`).
- Чеки самозанятого — демонстрационные, без регистрации в ФНС.
- Токен для SSE передаётся в адресе запроса.
- API рассчитан на один экземпляр.
