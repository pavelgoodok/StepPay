# Сквозные тесты

Сценарии в браузере: регистрация, вход, оплата по шагам, спор, чат и регистрация задачи, отзывы и рейтинг, краудфандинг, грант, возврат проекта на доработку, панель администратора, подтверждение данных, мобильная вёрстка.

Запуск (из корня репозитория):

```
pnpm --filter @steppay/web build        # NEXT_PUBLIC_API_URL=http://localhost:4000
pnpm --filter @steppay/e2e exec playwright install chromium
pnpm e2e
```

Playwright сам запускает API (демо-режим, память) и веб-часть. Если браузер уже установлен, укажите путь в `PW_CHROMIUM`.
Сценарии идут по очереди и перед каждым сбрасывают демо-состояние.
